# InspectAI — Agentic Visual Quality Inspector

**See the defect. Investigate the evidence. Decide what happens next.**

InspectAI localizes visual anomalies on manufactured-object surfaces using
**OpenCV 5**, then runs an **explicit agentic decision loop** that evaluates its
own evidence and chooses the next action — re-inspect, pass, flag, or escalate
to a human — with a full, auditable decision trace.

Built for the **OpenCV AI Competition 2026, powered by AWS**
(<https://opencv26.devpost.com/>). Verified engine: **OpenCV 5.0.0**.

> ⚠️ InspectAI is decision-support, **not** a certified inspector. A flagged
> region is a *potential* visual anomaly and requires human verification.
> See [`docs/responsible_use.md`](docs/responsible_use.md).

## Quick start

```bash
# From the inspectai/ directory, Python 3.11
pip install -r requirements.txt

# Verify OpenCV 5
python -c "import cv2; print(cv2.__version__)"   # -> 5.0.0

# Generate stable demo samples + charts (optional)
python scripts/make_samples.py
python scripts/make_charts.py

# Run the reproducible evaluation (writes artifacts/evaluation_results.json)
python -m src.evaluation.evaluate

# Run the tests
python -m pytest -q

# Launch the UI (in-process pipeline)
streamlit run app.py
```

### Run the API (what deploys to AWS)

```bash
uvicorn src.api.routes:app --host 0.0.0.0 --port 8080
curl http://127.0.0.1:8080/health
# POST an image:
# curl -F "file=@samples/spot.png" http://127.0.0.1:8080/inspect
```

Point the UI at a remote API instead of running in-process:

```bash
# Windows PowerShell
$env:INSPECTAI_API_URL = "https://<service>.us-east-1.awsapprunner.com"
streamlit run app.py
```

## Try the agentic behavior

In the UI, pick **Sample kind** and **seed**:

- `normal`, seed **101** → **No anomaly detected** (clean pass).
- `spot`, seed **303** → **Potential anomaly** (clear, terminates immediately).
- `scratch`, seed **102** → borderline → agent **re-inspects**, can't
  corroborate → **Human review required**.
- `scratch`, seed **111** → borderline → agent **re-inspects**, corroborates →
  **Potential anomaly**.

Seeds 102 vs 111 are the headline demo: the agent takes the *same* follow-up
action but reaches *different* conclusions, both driven by the real first
result. Open the **Agent decision trace** to see every step.
